# Богатыри против нечисти

Игра для Telegram Mini App в духе Vampire Survivors: богатыри из русских сказок идут на Кощея через три локации, оружие бьёт само, игрок ведёт героя пальцем и выбирает улучшения. До 2026-10-28 игра называлась «Коты против пылесосов»: внутренние id (`cats`, `ryzhik`, `flat`, `robot` и т.п.) остались от неё, чтобы старые забеги воспроизводились. Сейчас идёт переход с прошлой игры «Отряд» (автобаттлер, его код ещё в репозитории), прототип новой игры лежит в `packages/client/public/proto/survivors.html`.

- План разработки: [docs/PLAN.md](docs/PLAN.md)
- Сервер, API и развёртывание: [docs/server.md](docs/server.md)
- Прошлая игра «Отряд»: [docs/archive/](docs/archive/)

## Структура

- `packages/core` — правила игры: бой, лавка, бойцы. Один код для клиента и сервера.
- `packages/client` — игра (Vite), работает в Telegram и в браузере, онлайн и офлайн.
- `packages/server` — сервер: вход через Telegram, забеги, бои, соперники (Fastify + PostgreSQL).
- `tools/cats-balance.ts` — баланс по забегам ботов (`npm run balance:cats`), `tools/load.ts` — нагрузочная проверка сервера.

## Команды

Нужен Node.js 22.18 или новее (запускает TypeScript без сборки).

```sh
npm install
npm test          # автотесты ядра
npm run typecheck # проверка типов
npm run balance   # симуляция баланса, по умолчанию 3000 забегов
npm run dev       # прототип на http://localhost:5173
npm run build     # сборка прототипа в packages/client/dist
```

## Графика

Все герои, враги, снаряды и препятствия нарисованы в коде простыми фигурами (`packages/client/src/cats/sprites.ts`). Персонажи взяты из былин и народных сказок (Илья Муромец, Баба-Яга, Кощей, Змей Горыныч и т.д.) в своём рисунке: облик героев из мультфильмов «Мельницы» и советских мультфильмов не используется.
