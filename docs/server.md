# Сервер «Отряда»

Сервер хранит забеги, сам проводит бои и подбирает соперников из отрядов других игроков. Клиент только показывает игру: он присылает действия хода, сервер повторяет их тем же ядром (`packages/core`) и не доверяет результату клиента.

## Как это работает

1. Mini App открывается, клиент берёт подписанные Telegram данные запуска (`initData`) и шлёт их в заголовке `Authorization: tma <initData>`.
2. Сервер проверяет подпись токеном бота. Пароли и регистрация не нужны.
3. В лавке клиент применяет действия у себя для мгновенного отклика и копит их.
4. По кнопке «В бой» клиент отправляет действия хода. Сервер:
   - восстанавливает забег из базы и повторяет действия;
   - отклоняет запрос, если какое-то действие нарушает правила;
   - подбирает отряд-призрак того же раунда с близким числом побед;
   - проводит бой, сохраняет забег, а отряд игрока записывает призраком для других.
5. Если запрос отклонён, клиент берёт состояние с сервера.

Защита от двойной отправки: у забега есть версия, и ход со старой версией получает ответ 409.

Если сервер недоступен или игра открыта не в Telegram, клиент играет офлайн, как раньше.

## API

| Запрос | Что делает |
|---|---|
| `GET /api/health` | проверка, что сервер жив |
| `GET /api/me` | имя игрока и статистика |
| `GET /api/runs/current` | текущий забег или `null` |
| `POST /api/runs` | новый забег (старый закрывается) |
| `POST /api/runs/:id/turn` | `{ version, actions }` → новое состояние, бой, имя соперника |

Ограничение: 120 запросов в минуту на игрока.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | проверка подписи игроков, обязательна |
| `DATABASE_URL` | PostgreSQL; без неё данные в памяти и пропадают при перезапуске |
| `CORS_ORIGIN` | адреса клиента через запятую, если клиент живёт не на сервере (например `https://biktorb.github.io`) |
| `STATIC_DIR` | папка собранного клиента, чтобы сервер отдавал и игру |
| `PORT` | порт, по умолчанию 3000 |
| `DEV_AUTH=1` | только для разработки: вход заголовком `dev <id>` без Telegram |

Токен бота храните только в переменных окружения или `.env` на сервере, никогда в репозитории.

## Локальный запуск

```sh
# PostgreSQL на localhost с базой otryad
DATABASE_URL=postgres://otryad:otryad@localhost/otryad DEV_AUTH=1 \
CORS_ORIGIN=http://localhost:5173 npm start -w @otryad/server

# клиент, который ходит в этот сервер
VITE_API_URL=http://localhost:3000 npm run dev
# открыть http://localhost:5173/?dev=1
```

Тесты на PostgreSQL: `TEST_DATABASE_URL=postgres://… npm test` (без переменной тесты идут только на хранилище в памяти).

Нагрузочная проверка против сервера с `DEV_AUTH=1`: `node tools/load.ts http://localhost:3000 200 5`.

## Развёртывание на VPS

Нужен VPS с Docker (1 ГБ памяти хватит на старт) и домен: Telegram открывает Mini App только по HTTPS.

1. Склонировать репозиторий на сервер и создать рядом `.env`:
   ```
   TELEGRAM_BOT_TOKEN=…
   POSTGRES_PASSWORD=длинный-случайный-пароль
   ```
2. `docker compose up -d --build` поднимет PostgreSQL и сервер на порту 3000. Миграции базы и стартовые отряды-боты применятся сами.
3. HTTPS проще всего получить через Caddy: он сам выпускает сертификат. Пример `Caddyfile`:
   ```
   game.example.com {
     reverse_proxy localhost:3000
   }
   ```
4. В @BotFather через `/myapps` поменять адрес Mini App на `https://game.example.com/`. Сервер отдаёт и игру, и API с одного адреса, поэтому CORS не нужен.

Вариант без переноса клиента: оставить игру на GitHub Pages, задать в репозитории переменную `API_URL` (Settings → Secrets and variables → Actions → Variables) с адресом сервера и перезапустить «Deploy prototype». Тогда серверу нужен `CORS_ORIGIN=https://biktorb.github.io`.

## Проверено (25.10.2026)

- 39 автотестов: проверка подписи Telegram, полный ход, двойная отправка, недопустимые и поддельные действия, чужой забег, призраки. Отдельный тест сверяет клиент и сервер на случайной игре в лавке, расхождений нет. Всё прогоняется и на памяти, и на PostgreSQL.
- Полный забег в браузере через сервер: 10 ходов, все приняты.
- 200 игроков одновременно по 5 ходов: 1200 запросов за 1,8 с, p95 460 мс, ошибок нет.
- Забеги переживают перезапуск сервера.
- Docker-образ собирается, применяет миграции, засевает 746 отрядов-ботов и отдаёт игру.

Известное ограничение: состояние генератора случайных чисел лавки есть у клиента, поэтому теоретически можно заранее узнать, что выпадет при обновлении лавки. Бой при этом считается только на сервере. Если это станет проблемой, обновление лавки можно перенести на сервер.
